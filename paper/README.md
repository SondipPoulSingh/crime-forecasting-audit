# Manuscript

Target journal: *Computers, Environment and Urban Systems* (Elsevier). Class `elsarticle` (preprint, author-year), bibliography style `elsarticle-harv`.

- `main.tex` — anonymized manuscript for double-anonymized review (`\anonymoustrue`); `main_with_authors.tex` — the same with authors, repository link and CRediT; `title_page.tex` — separate title page with author details; `references.bib` — references (each checked against Crossref, the publisher, arXiv or the proceedings site); `highlights.txt` — highlights (≤ 85 characters each).
- `supplementary.tex` — Supplementary Material (Tables S1–S15), generated by `scripts/make_supplement.py`.
- `figures/*.pdf` are generated by `scripts/make_figures.py` and `scripts/make_figures_spatial.py`, and `tables/*.tex` were first generated by `scripts/make_tables.py`, from `results/`.
- **Submission revision (12 Nov 2026):** Table 3 now ranks ten models (ST-SHN once, with its validation-selected epoch), Tables 2, 3 and 7 were re-laid out, wide tables are wrapped in `adjustbox`, and the bootstrap and 2020-shift tables moved to the Supplement (S13, S14). Re-running `make_tables.py` restores the earlier layout, so do not run it before re-applying these changes. Supplementary Table S15 (in-city re-scoring) comes from `scripts/analysis_in_city_rescoring.py`.

Compile: `pdflatex main && bibtex main && pdflatex main && pdflatex main` (or upload the folder to Overleaf).

Compile the Supplementary Material separately: `pdflatex supplementary` (twice).
