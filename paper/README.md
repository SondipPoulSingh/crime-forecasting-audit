# Manuscript

Target journal: *Computers, Environment and Urban Systems* (Elsevier). Class `elsarticle` (preprint, author-year), bibliography style `elsarticle-harv`.

- `main.tex` — manuscript; `references.bib` — references (each checked against Crossref, the publisher, arXiv or the proceedings site); `highlights.txt` — highlights (≤ 85 characters each).
- `tables/*.tex` and `figures/*.pdf` are generated by `scripts/make_tables.py` and `scripts/make_figures.py` from `results/tables`; do not edit them by hand.

Compile: `pdflatex main && bibtex main && pdflatex main && pdflatex main` (or upload the folder to Overleaf).
